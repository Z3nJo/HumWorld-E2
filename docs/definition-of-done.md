# Definition of Done

Una tarea o historia se considera terminada cuando:

1. El codigo esta versionado en GitHub.
2. Los cambios fueron revisados por al menos un integrante distinto del autor.
3. La documentacion relacionada fue actualizada en `docs/`.
4. Los endpoints modificados o creados estan reflejados en la documentacion OpenAPI/Swagger cuando aplique.
5. Existen pruebas unitarias para la funcionalidad cuando aplique.
6. Existen pruebas de integracion cuando la funcionalidad cruza capas.
7. El entorno Docker levanta sin errores si el cambio afecta configuracion o despliegue.
8. El pipeline CI/CD queda en verde.
9. No existen vulnerabilidades criticas o bloqueantes reportadas sobre codigo nuevo.
10. La funcionalidad fue validada manualmente contra sus criterios de aceptacion.
