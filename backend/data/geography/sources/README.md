# Fuentes locales del catálogo

Copiar aquí las fuentes descargadas de REST Countries y GeoNames antes de
ejecutar el generador. Los datasets se excluyen de Git y de la imagen Docker
habitual; no son necesarios para arrancar el backend.

Consultar [el procedimiento del catálogo](../README.md). No colocar credenciales
ni enlaces a archivos fuera del ámbito autorizado.
