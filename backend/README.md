# Backend

Este modulo contendra la API REST y la logica de negocio de HumWorld.

Responsabilidades previstas:

- Captura automatica y manual de fuentes RSS.
- Gestion de fuentes, noticias, diccionario y configuracion.
- Calculo de humor mediante analisis de sentimiento.
- Purgado automatico y manual de noticias antiguas.
- Exposicion de endpoints bajo `/api/v1`.
- Documentacion Swagger/OpenAPI en `/api/docs`.

En Sprint 0 este modulo solo contiene un `Dockerfile` base para validar el entorno.
