# Frontend

Este modulo contendra la interfaz web de HumWorld.

Vistas previstas:

- Panel de administracion para fuentes RSS, diccionario y configuracion.
- Dashboard de humor con mapa mundial interactivo.
- Nube de palabras filtrable por pais o continente.
- Listado de noticias influyentes.

En Sprint 0 este modulo solo contiene un `Dockerfile` base para validar el entorno.
