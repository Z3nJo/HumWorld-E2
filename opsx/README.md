# Opsx

Esta carpeta contiene la configuracion operativa del proyecto.

En Sprint 0 incluye el archivo `docker-compose.yml`, que levanta contenedores base para backend y frontend.

## Levantar el entorno

```bash
docker compose up --build
```

## Detener el entorno

```bash
docker compose down
```

Mas adelante esta carpeta podra incorporar configuraciones de entorno, contratos OpenSpec y archivos de despliegue.
